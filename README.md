## 功能

- [x] 翻译 [TETR.​IO](https://tetr.io/) 至中文
  - [x] 支持翻译游戏内画面和页面文本内容
  - [x] 支持动态生成字体文件[^1]
- [x] 支持客户端和网页端使用

[^1]: 如果是客户端则支持兼容在 TETR.​IO PLUS 中设定的自定义字体，中文文本会使用另一个固定的字体
